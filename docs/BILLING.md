# SAAS BILLING — DOCUMENTAÇÃO DE PLANOS E LIMITES

## 1. Planos Disponíveis
* **Free (R$ 0/mês):** 50 créditos/mês, 1 campanha, modo simulação, CRM básico.
* **Starter (R$ 297/mês):** 500 créditos/mês, 5 campanhas, disparos reais, enriquecimento básico.
* **Pro (R$ 797/mês):** 2.000 créditos/mês, 20 campanhas, testes A/B, API pública, marketplace.
* **Enterprise (R$ 1.997/mês):** 10.000 créditos/mês, campanhas ilimitadas, marketplace exclusivo, suporte dedicado.

## 2. Concessão de Créditos
Ao assinar ou renovar um plano, o saldo de créditos é automaticamente incrementado com registro de auditoria (`PLAN_GRANT`).
